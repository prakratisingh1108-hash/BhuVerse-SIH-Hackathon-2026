# BhuVerse - SIH Hackathon 2026

**SIH 2026 | Team: BhuVerse | PS Title: 3D ULPIN Generation and Vertical Property Mapping System | Team ID: 121110 | Category: Software**

### 📌 Problem Statement
Development of a 3D ULPIN Generation and Vertical Property Mapping System for urban land records to handle multi-storey properties, vertical ownership, and 3D visualization.

### 💡 Our Solution - BhuVerse
BhuVerse is a 3D GIS-based platform that generates Unique Land Parcel Identification Numbers (ULPIN) in 3D and maps vertical properties (floor-wise ownership) for transparent, tamper-proof urban governance.

**Key Features:**
- 3D ULPIN Generation for each floor/unit
- Vertical Property Mapping (G+ N floors)
- 3D Visualization of Buildings (CesiumJS / Three.js)
- AI-based Floor Detection from Blueprint/Satellite
- Blockchain-secured Property Records

### 🛠️ Tech Stack
- **Frontend:** React.js, CesiumJS, Three.js
- **Backend:** Node.js / Python (FastAPI), PostGIS
- **AI/ML:** OpenCV, YOLO for floor detection, PyTorch
- **GIS:** QGIS, PostGIS, OpenStreetMap, Bhuvan API
- **Database:** PostgreSQL + PostGIS

### ✅ Feasibility & Risk Mitigation
**Feasibility:** Our solution is feasible via a small-scale MVP built on open-source GIS & AI stack using publicly available and synthetic data. 

**Key Risks & Mitigation:**
- **Data Inconsistency:** Multi-source Data Fusion
- **AI Errors:** AI + Rule-based + Human-in-the-loop Verification
- **3D Complexity:** LOD-based rendering
- **Privacy & Legal:** Role-based Secure Access Control & Human Legal Verification
- **Scalability:** Modular architecture scalable from one locality to entire city.
